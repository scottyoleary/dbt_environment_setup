# setup-dbt.ps1 test matrix

How to read the **Verified** column:

- **Simulated** = the full script ran under PowerShell 7.5.4 on Linux, against PyPI and real uv downloads. A test-only copy swapped `Scripts\python.exe` for `bin/python`, and Windows environment variables pointed at temp folders.
- **Unit** = the helper functions were called directly with real files and the real dbt-fabric 1.10.1 venv.
- **Static** = PSScriptAnalyzer 1.24.0 compatibility rules against the Windows PowerShell 5.1 profile (0 findings), plus a parse check, a 7-only syntax scan and an ASCII-only check.
- **Windows** = still needs a run on a real Windows 10/11 box. Use a standard (non-admin) user, ideally a fresh VM or Windows Sandbox snapshot per row.

Exit codes: `0` OK, `1` failed, `2` changes needed (`-CheckOnly` only).

## Unit coverage (all passing)

- **Native runner**: stdout/stderr capture, non-zero exit codes, a missing command not reporting a stale `$LASTEXITCODE`, and arguments containing spaces or quotes.
- **Python probe**: accepts 3.12 and 3.13; rejects 3.11, 32-bit, missing interpreters and venv interpreters (falling back to the base). A `json.py` in the current folder can't break it.
- **requirements.txt**: created, missing pins appended, name normalization (`dbt_core`), mismatched, unpinned and fork lines stop the run.
- **Lock**: parses both pip-freeze and `uv pip compile` output (64 packages), catches stale locks, and diffs against installed versions while listing extras.
- **VS Code**: create, no-op re-run, comment preservation, CRLF and indent detection, an equivalent forward-slash path treated as no change, `{}`, unparseable files left alone, commented-out duplicate keys, `unwantedRecommendations`, and empty and populated `recommendations` arrays.
- **.gitignore**: create, append only what's missing (`/target/` counts as present), LF kept, no-op re-run, UTF-16 files left untouched.
- **Profiles**: create, re-run, append with backup, parse error, `DBT_PROFILES_DIR`, repo-local `profiles.yml`, target-only `env_var()` detection (defaults ignored), regex fallback without a `.venv`.
- **`dbt --version`**: parsing matches real dbt 1.10.15 output.
